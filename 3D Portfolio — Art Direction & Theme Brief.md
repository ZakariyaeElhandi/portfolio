# 3D PORTFOLIO — ART DIRECTION / THEME BRIEF

## 1. Overall Concept

Create a **dark futuristic 3D developer portfolio that feels like entering the personal digital world of a technical creator**.

This should NOT feel like a normal portfolio website with a 3D model placed in the background.

The **3D environment IS the portfolio**.

The visitor should feel like they are exploring a mysterious futuristic digital space where each area represents a different part of my skill set.

The experience should communicate:

> **"This isn't just a portfolio. This is an interactive world built by the person you're discovering."**

The design should combine:

**Cyberpunk + Sci-Fi + Digital Laboratory + Game Environment + Developer Interface**

without becoming excessively neon or visually noisy.

---

- Technical
- Creative

# 3. Main Visual Theme

### "THE DIGITAL LABYRINTH"

The entire website can be conceptually treated as a futuristic digital labyrinth.

The visitor enters a central environment.

From there, different paths / portals / structures lead toward different disciplines.

For example:

**CORE**

→ AI / DATA  
→ ENTERPRISE / ODOO  
→ WEB / MOBILE  
→ 3D / GAME DEV  
→ PROJECTS

The environment should subtly communicate that these are different parts of the same person rather than completely separate identities.

# 5. Color Direction

Primary:

- Near-black
- Charcoal
- Very dark gray

Secondary:

- Metallic gray
- Desaturated blue
- Deep violet
- Dark cyan

Accent:

Use **one primary accent color** consistently for important interactive elements.

Possible accent:

**Electric cyan / blue**

Optional secondary accent:

**Purple**

The colors should remain relatively restrained.

The goal is:

**dark + premium + cinematic**

rather than:

**RGB gamer setup + excessive neon.**

---

# 6. Lighting

Lighting is extremely important.

Use cinematic lighting to make the 3D environment feel alive.

Possible elements:

- Volumetric-looking light
- Rim lighting
- Soft emissive surfaces
- Light beams
- Subtle fog
- Ambient particles
- Reflections
- Glowing screens
- Dynamic lights around important objects

Major project objects should have slightly stronger lighting so the visitor naturally notices them.

---

# 7. Navigation Philosophy

The navigation should feel like **exploration**, not browsing a website.

Instead of:

HOME → ABOUT → PROJECTS → CONTACT

the user should feel like:

**ENTER → EXPLORE → DISCOVER → INTERACT**

However, usability is still important.

Always provide a simple UI fallback such as:

- Menu
- Map
- Sections
- Projects
- About
- Contact

The 3D experience should be immersive without becoming frustrating.

# 15. Existing Animations

I already have **Three.js animations and assets that I intend to integrate**.

The website should therefore be designed to accommodate existing animations instead of forcing everything into a predefined template.

The agent should create a modular architecture where:

- Existing 3D animations can be inserted easily
- GLTF / GLB assets can be replaced
- Animation clips can be triggered by interaction
- Camera animations can be customized
- Objects can have independent animation states
- Scroll / mouse / keyboard interactions can control animations
- New scenes can be added without rebuilding the entire application

The architecture should prioritize **easy integration of custom 3D assets and animations**.

---

# 16. Animation Style

Animations should feel:

- Smooth
- Cinematic
- Deliberate
- Weighty
- Responsive

Avoid:

- Excessive bouncing
- Random spinning
- Generic website transitions
- Overly fast animations

Use:

- Camera movement
- Object reveal animations
- Scale transitions
- Floating motion
- Light activation
- Particle effects
- Holographic UI transitions
- Smooth camera interpolation
- Depth-of-field-like effects where practical

The world should contain small details that reward exploration.

- Objects react when approached

- Screens display information

- Portals open
- Hidden references to projects

These details should make the portfolio feel like an actual world.

# 18. UI Design

The HTML UI should complement the 3D world rather than dominate it.

Use:

- Thin borders
- Minimal panels
- Small technical labels
- Monospaced typography for technical information
- Clean modern typography for headings
- Subtle glass / holographic panels
- Small status indicators
- Minimal icons

Possible interface language:

**SYSTEM ONLINE**

**NODE_04**

**PROJECT_DATABASE**

**AI_MODULE**

**3D_ENGINE**

**ACCESS_PROJECT**

But don't overuse fake "hacker" terminology.

It should feel like a **real high-end digital interface**, not a cliché hacker screen.

# 21. Reference / Inspiration

### Primary reference: Bruno Simon's 3D Portfolio

Use **Bruno Simon's portfolio** as inspiration for the **concept of turning a portfolio into an interactive 3D world**, not for copying its visual identity.

His portfolio essentially turns the website into an explorable world where the visitor moves through the environment to discover the creator and the projects. It is built using Three.js and includes keyboard/gamepad interaction, interactive objects, a map, and other game-like systems.

Reference:

[Bruno Simon — 3D Portfolio](https://bruno-simon.com/?utm_source=chatgpt.com)

### What to take from it

- Portfolio as a world
- Exploration instead of conventional navigation
- 3D interaction
- Game-like discovery
- Strong personality
- Technical showcase
- Easter eggs
- Interactive environment

### What NOT to copy

Do NOT reproduce:

- His car concept
- His exact environment
- His colors
- His typography
- His UI
- His level design
- His specific gameplay mechanics

Instead, create a completely original **dark futuristic digital-labyrinth identity** based on my own profile.
